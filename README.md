# ETNADE — Base de Conocimiento (Wiki)

Base de conocimiento en Markdown que utiliza el agente de IA del proyecto de automatización de ETNADE para responder consultas de forma precisa.

> Este repo es la fuente de información del agente conversacional. La lógica de automatización está en [Workflow-n8n-tecnoteca](https://github.com/gonzacordobani1889-ui/Workflow-n8n-tecnoteca).

## 📖 Contenido
Archivos Markdown organizados por tema (información institucional, aranceles, procesos administrativos, etc.), consultados por el agente de IA en tiempo real.

## 💡 Por qué Markdown y no Google Docs
Se migró desde Google Docs a archivos Markdown versionados en GitHub para facilitar el mantenimiento, el control de cambios y la integración directa con el agente de IA.

## 🌐 Interfaz
También incluye la interfaz web (HTML) deployada en GitHub Pages para consulta directa.
